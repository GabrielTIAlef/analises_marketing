# Evidências da demonstração

Somente dados fictícios gerados por este repositório. Os gráficos, perfis, comparação de k e resumo correspondem à demonstração de 180 linhas com semente 42. O resumo inclui hash da entrada e versões. Não são dados originais de clientes nem resultados de campanhas.

tests-result.json e notebook-result.json são registros locais. Não devem ser apresentados como execução do GitHub Actions. Confira docs/VALIDACAO.md para o estado da publicação e as limitações.
